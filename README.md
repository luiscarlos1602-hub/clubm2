# Club M² · club de inversión inmobiliaria

Plataforma web del club: landing y registro, marketplace de proyectos con simulador de reparto 25/75, portafolio, club y backoffice (adquisiciones, obras, comercialización, finanzas, CRM). **Etapa 1: proyectos y participaciones con datos simulados. No es una oferta de inversión.**
